Kasa – Application de location immobilière en React

Kasa est une plateforme de location d’appartements développée en React.
Le projet consiste à intégrer une maquette Figma et créer une application Single Page (SPA) dynamique avec React Router, tout en assurant une navigation fluide, une bonne gestion des erreurs, et un composant UI réutilisable.

Compétences mises en œuvre
- Créer une application avec React (v18)
- Utiliser React Router pour la navigation
- Manipuler des props, états et composants dynamiques
- Gérer des composants réutilisables (accordéons, galeries, tags)
- Implémenter une page 404 personnalisée
- Respecter les contraintes d’accessibilité

Fonctionnalités principales
Page d’accueil avec liste de logements

Page logement avec :
- Carrousel d’images
- Étiquettes (tags)
- Accordéons pour description/équipements
- Évaluation par étoiles
- Page "À propos" avec accordéons d’infos
- Gestion des routes dynamiques (/logement/:id)
- Page 404 personnalisée en cas d’URL invalide

🛠️ Technologies utilisées
- React 18
- React Router DOM v6+
- Sass / CSS Modules
- JavaScript (ES6+)
- Git & GitHub

🚀 Installation
1. Cloner le dépôt
```git clone https://github.com/coralinepa/Kasa.git```
```cd Kasa```
2. Installer les dépendances
```npm install```
3. Lancer le projet
```npm start```
Le site sera accessible à http://localhost:3000
